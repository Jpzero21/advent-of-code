# advent-of-code

My Advent of Code solutions 🎅🎄

#### Running a solution

Run a specific solution using cargo

```bash
cargo run -p aoc{year}_d{day}
```

For example

```bash
cargo run -p aoc2022_d10
```

#### Viewing the puzzle's text

View the puzzle's text for a given day

```bash
cat puzzles/{year}/d{day}/puzzle.txt 
```

For example

```bash
cat puzzles/2022/d10/puzzle.txt
```

#### Get the puzzle input

View the puzzle's input(s) for a given day

```bash
cat inputs/{year}/d{day}/input.txt 
```

For example

```bash
cat inputs/2022/d10/input.txt
```

If a puzzle has more than one input, `ls` the directory to view the naming for each file

```bash
ls inputs/2022/d05/
```
